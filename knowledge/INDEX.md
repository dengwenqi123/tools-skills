# tools-skills 知识索引

本文件常驻上下文，只列目录。具体内容按需用 read 工具读取对应文件，不要凭记忆回答。

目录：`{{ROOT}}/knowledge/`

- `COMMON.md`：链接转换规则。给出 vela_crash_report?id=、珊瑚海 task_id 链接时，读它来拿到查询详情的接口地址。
- `Tools.md`：常用 MCP 选型，比如查线上库、查 matrix 日志、两个 Jira 实例各用哪个工具。
- `JIRA_PROJECT.md`：Jira 项目前缀属于 jira.n 还是 jira-phone。拿到单号、不确定该查哪个实例时读它。
- `Project.md`：vela-tool-service、bug_agents 等项目的仓库地址、部署域名、分支、提交方式。
- `Nodes.md`：vela / mina / host 节点的主机名、IP、ssh 登录方式，以及 crash 分析日志路径。
- `CONTEXT.md`（450 行）：vela-tool-service 的领域词汇表，包括 crash 资源状态、提单路径、就绪判定、崩溃归因、解析机与 agent 实例、提单/分析回归、OneTrack、自动化测试看板、alarm 同步、垂域指标、AI 周报。遇到这些术语时，先 grep 定位到对应的 `## ` 章节，只读那一节。
